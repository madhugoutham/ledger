Ledger

Who shipped what?

Merged pull requests, reviews and issues in every repository of the selected organizations, consolidated per org.

How this is counted

Everything comes straight from the GitHub API, from your browser, with your own token. Nothing is stored anywhere else.

  • Merged PRs are pull requests you authored that were merged inside the window (is:pr is:merged author:you org:… merged:from..to). Forks and bots are excluded.
  • Reviews and issues come from GitHub's own contribution counts for the org and window (contributionsCollection), so they match your profile graph.
  • Commits are shown for context but not scored: in squash-merge orgs one PR is one commit, so scoring both would count the same work twice.
  • Score = . Three dimensions, never a single count. The weights are a convention, not a judgement.
  • The leaderboard is a short window, not all time, and lists everyone who merged a PR, not only org members.

This board is for seeing work, not grading people. Please do not use it for performance reviews, pay or promotion; review and triage work is undercounted by every metric here.

Connect to GitHub

Create a fine-grained token with no repository access and no permissions. Public data is readable by default, and a token with nothing attached cannot do anything else if it leaks.

A classic token with no scopes also works. The token stays in this browser and is sent only to api.github.com.
